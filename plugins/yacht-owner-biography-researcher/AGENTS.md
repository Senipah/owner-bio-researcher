# Plugin maintenance

Read README.md, plugin.json and skills/research-owner-biography/SKILL.md first. Preserve the manual, public-source research workflow, complete human-readable default response, exact owner-page field order, schema-v8 manual dossier constraints, active-tag whitelist and no-live-website rule.

Edit the SKILL.md and manifest directly. The three runtime references are generated by tools/build_plugin.py from the canonical repository skill and tag governance sources; edit those sources and rebuild. Do not edit archive/owner-biography-gpt or run the deprecated GPT generator. Run --check, the plugin and tag-backfill tests, and --package before handoff. Run VALIDATION.md in the target host before relying on a release, and report unrun host tests honestly.

Keep runtime files self-contained. Do not bundle exports, credentials, local state or the full non-assignable tag registry. Creating a ZIP is not authorisation to install, upload, update or share a hosted plugin.
